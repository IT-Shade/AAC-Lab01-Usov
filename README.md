##1 Тип системы совпадает с тем, что сообщила программа.
##2 Я думаю, что число ядер покажет 4.
Это число не означает, что в процессоре столько же физических ядер.
Логические процессоры совпадают, с тем что вывела программа.
##3 Память процесса в программе 15 МБ, память процесса в диспетчере задач 2464 КБ.
##4 На результат кода влияют внешние данных и состояние системы, поэтому код выдаёт разные результаты.

1. Программа узнаёт имя системы, запрашивая его, пи выполнении кода.
2. Операционная система является менеджером при запросе сведений.
3. 64-битная ОС означает, что она может работать с 64-битными процессорами.
4. Environment.ProcessorCount показывает число логических процессоров. Число может не совпадать с числом физических ядер.
5. WorkingSet - это количество памяти, которое выделено для процесса в данный момент.
6. На результат кода влияют внешние данных и состояние системы, поэтому код выдаёт разные результаты.
   ##Итоговый вывод
   Из-за того, что компьютеры имеют разные комплектующие и настройки, то при запуске кода результат будет разный.
